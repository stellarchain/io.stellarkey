# Support

For product help, use <https://stellarkey.io/support>. The site reveals the support address only after a user action so the mailbox is not published in static source.

Use a public GitHub issue for a non-sensitive, reproducible software defect or feature request. Include the StellarKey version and commit from About, device and browser versions, selected network, expected result, and sanitized reproduction steps. Search existing issues first.

Never publish a recovery phrase, private key, vault password, passkey material, signed transaction, customer record, or unredacted backup. Security concerns belong in the private process described in `SECURITY.md`.

StellarKey is self-custodial and has no account database or recovery operator. The project cannot recover lost secrets, unlock a vault, reverse a payment, refund an on-chain transaction, access browser-local merchant data, or mediate a dispute. Support is not financial, tax, or legal advice.
